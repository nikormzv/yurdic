# Password Manager

Password Manager is a lightweight Python application for organizing passwords locally.

The project demonstrates a modular structure for storing account credentials, generating secure passwords and exporting vault information. It is intended as a learning project and does not replace professional password management software.

## Features

- Store account records
- Password generator
- Password strength indicator
- Search by service
- Export vault summary
